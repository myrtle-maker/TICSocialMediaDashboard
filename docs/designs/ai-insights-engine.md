## Vision

### 10x Check
Transform from a metrics dashboard into an AI social media strategist. The tool should feel like having a senior social media director who knows every post, every metric, and gives specific weekly game plans. Not just "your engagement dropped" but "post 3 educational TikToks with question hooks on Tuesdays at 7pm, skip Facebook this week."

### Platonic Ideal
A brilliant social media director sitting next to you who celebrates wins, explains why they worked, warns before mistakes, and gives weekly game plans. The user feels confident and informed -- like they have an unfair advantage over competitors who are just guessing.

## Technical Decisions

- **LLM Provider:** Claude API (Anthropic SDK) -- best analytical reasoning
- **Email Service:** Resend -- modern API, React email templates, generous free tier
- **Auth:** Simple shared password via DASHBOARD_PASSWORD env var
- **Cron:** Vercel Cron Jobs for scheduled auto-scraping

## Environment Variables (new)

- `ANTHROPIC_API_KEY` -- Claude API for AI features
- `RESEND_API_KEY` -- Email delivery for weekly digest
- `DASHBOARD_PASSWORD` -- Simple auth for dashboard access

## Design Specifications

### Design System (implicit, from existing codebase)
- **Colors:** zinc-50 to zinc-900, blue-600 accent, green-500/yellow-500/red-500 for status
- **Components:** shadcn Card/Badge/Tabs/Button/Select/Tooltip
- **Spacing:** Tailwind scale (gap-4, gap-6, py-6, px-6)
- **Radius:** rounded-xl cards, rounded-lg buttons
- **Dark mode:** All components support dark: classes

### New Design Patterns
- **Health scores:** Radial gauge circles (like Apple Watch rings), color-coded:
  green-500 >= 70, yellow-500 >= 40, red-500 < 40. Include numeric label for a11y.
- **AI briefing text:** Streamed (typewriter effect), styled like a memo with
  subtle left border accent (border-l-4 border-blue-500), slightly different
  font weight. NOT inside a generic Card.
- **Content predictor score:** Animated fill bar, gradient red-to-green based on score.
- **Competitor comparison:** Hero bar chart (your ER vs theirs), NOT card grid.
- **Post comparison diff:** Green highlight = you outperformed, red = they did.
- **Hook library cards:** Hook text prominent, performance metrics secondary,
  copy button always visible.
